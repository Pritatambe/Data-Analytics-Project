# Data Analytics Portfolio

A curated portfolio of end-to-end data analytics projects demonstrating skills in **SQL, Python (EDA), Tableau, Excel, PostgreSQL, and HiveQL**.

## Skills & Tools

* **SQL:** Data cleaning, data exploration, joins, aggregations, and analytical queries
* **Python:** Exploratory Data Analysis (EDA) using Jupyter Notebook
* **Tableau:** Dashboard development and data visualization
* **Excel:** Pivot Tables, Pivot Charts, slicers, lookups, formulas, and basic data modeling
* **PostgreSQL:** Database querying and business intelligence analysis
* **HiveQL:** Large-scale data analysis using Hadoop/Hive
